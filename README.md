# 🚢 Titanic Survival Data Cleaning

## 📌 Project Overview

This project focuses on **data cleaning and preprocessing** of the Titanic dataset. The main objective is to prepare raw and incomplete data for further **data analysis and machine learning**.

The project was completed as part of my **first internship project**, where I learned practical concepts related to handling real-world datasets.

## 🎯 Objectives

* Understand the structure of the Titanic dataset
* Identify missing values
* Handle missing and inconsistent data
* Remove unnecessary columns
* Detect and handle duplicate records
* Convert data into a suitable format for analysis
* Prepare a clean dataset for further machine learning tasks

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Jupyter Notebook / Google Colab
* Matplotlib *(if used)*

## 🔍 Data Cleaning Process

The following steps were performed:

1. **Data Loading** – Imported the Titanic dataset using Pandas.
2. **Data Inspection** – Checked rows, columns, data types, and dataset information.
3. **Missing Value Analysis** – Identified columns containing missing values.
4. **Missing Value Handling** – Applied appropriate methods to handle missing data.
5. **Duplicate Checking** – Checked for duplicate records.
6. **Column Cleaning** – Removed unnecessary columns where required.
7. **Data Type Handling** – Converted data types where necessary.
8. **Final Dataset Preparation** – Created a cleaner dataset suitable for further analysis.

## 📊 Dataset

The project uses the **Titanic dataset**, which contains information about passengers such as:

* Passenger Class
* Sex
* Age
* Number of siblings/spouses
* Number of parents/children
* Fare
* Embarkation location
* Survival status
